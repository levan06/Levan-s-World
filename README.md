# Levan's World

A 2D platformer game developed in Java using Swing.

> 🚧 This project is currently under development.

## Overview

Levan's World is a personal Java project focused on learning game development concepts such as:

- Character animation
- Keyboard input handling
- Game object rendering
- State management
- Object-oriented programming
- Java Swing graphics

The game features a knight character that can move through a 2D environment composed of platforms and terrain elements.

## Features

### Character Actions

- Idle animation
- Walking
- Running
- Jumping
- Attacking
- Climbing

### Environment

- Platforms
- Terrain tiles
- Decorative objects
- Background rendering

### Technical Features

- MVC-inspired architecture
- Sprite-based animations
- Java Swing rendering
- Keyboard controls
- Dynamic state transitions

## Technologies

- Java
- Java Swing
- BufferedImage
- Object-Oriented Programming
